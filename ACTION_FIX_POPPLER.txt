🎯 YOUR EXACT PROBLEM
═══════════════════════════════════════════════════════════════════════════════

Error Message:
  "Unable to get page count. Is poppler installed and in PATH?"

Root Cause:
  The `poppler` system library is NOT installed on your server

Server Location:
  /www/wwwroot/website/jawla/venv/
  → This is a Linux server (Ubuntu/Debian/CentOS)


⚡ EXACT COMMANDS TO RUN (Copy & Paste)
═══════════════════════════════════════════════════════════════════════════════

Option 1: If you're on Ubuntu/Debian (Most Likely)

1. SSH to your server:
   ssh root@your.server.com

2. Run these commands:
   sudo apt-get update
   sudo apt-get install -y poppler-utils tesseract-ocr

3. Verify installation:
   pdftoimage -v
   tesseract --version

4. Restart Django app:
   sudo systemctl restart digit_sport

5. Test:
   Go to web UI → Upload PDF → Should work now! ✅


Option 2: If you're on CentOS/RedHat

   ssh root@your.server.com

   pdftoimage -v

   sudo systemctl restart digit_sport

⏸️ IF YOU GET STUCK
═══════════════════════════════════════════════════════════════════════════════

Problem: "command not found: apt-get"
  → You might be on CentOS
  → Try: sudo yum install -y poppler-utils tesseract
  → Or check: cat /etc/os-release

Problem: "Permission denied"
  → You need sudo/root access
  → Either use sudo or ask hosting provider

Problem: "Still getting poppler error"
  → Didn't restart Django
  → Run: sudo systemctl restart digit_sport
  → Wait 10 seconds
  → Try again

Problem: "Can't SSH to server"
  → Check SSH credentials
  → Or use cPanel/hosting panel if available
  → Or ask hosting provider for SSH access
